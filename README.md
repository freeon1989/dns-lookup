# DnsLookup

Утилита для пакетного DNS-поиска и проверки TCP-портов в Windows. Поддерживает IPv4 и IPv6.

## DNS-поиск

1. Вставьте IP-адреса и имена серверов через пробел, запятую или с новой строки. Список также можно открыть из TXT-файла.
2. Оставьте поле DNS-сервера пустым для использования настроек Windows или введите IP нужного DNS-сервера.
3. На вкладке **DNS-поиск** нажмите **Выполнить поиск**. По IP утилита ищет PTR-записи, по имени — A и AAAA. При включённой сверке PTR утилита проверяет, возвращает ли найденное имя исходный IP.

Повторяющиеся IP выделяются жёлтым. Можно показать только строки с ошибками, повторить проблемные запросы, скопировать видимые строки в Excel или сохранить их в CSV. При отмене выполненные запросы остаются в таблице.

## Проверка TCP-портов

На вкладке **TCP-порты** введите отдельные порты и диапазоны, например `22, 80, 443, 8000-8010`, затем нажмите **Сканировать TCP-порты**. Утилита проверяет указанные IP и адреса, полученные для имён. В таблице появляются порты, к которым удалось подключиться. Отказы и тайм-ауты подсчитываются отдельно.

## Сборка

Для сборки нужен Windows с .NET Framework 4.5 или новее. Из корня репозитория запустите в PowerShell:

```powershell
.\build.ps1
```

Готовый файл появится в `dist\DnsLookup.exe`.
